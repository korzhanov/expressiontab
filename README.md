# expressiontab

Expression New Tab for Google Chrome.

Chrome extension that provides a new tab for managing browsing history and bookmarks, organized by host.

## Features

- **History search** – quick access to recently visited pages
- **Bookmark organization** – grouped by host for easy navigation
- **Search integration** – find both history and bookmarks in one place

## Quick Start

1. `bun install` – install dependencies
2. `bun run build` – build the extension
3. Open `chrome://extensions/`, enable "Load unpacked", select `builds/expressiontab`
