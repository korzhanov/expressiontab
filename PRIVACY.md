# Expression Tab Privacy Policy

Last Updated: 2026-09-23

## Overview

Expression Tab is a Chrome extension that provides a new tab experience with searchable history and bookmarks. This privacy policy explains how user data is handled.

## Data Collection

- **Web History**: Collected locally via `chrome.history.search` to display recently visited pages.
- **Bookmarks**: Collected via `chrome.bookmarks.search` to organize and display bookmarks by host.
- **No Personal Identifiable Information**: No names, emails, or other PII are collected.
- **No External Transmission**: All data remains local; no telemetry or external API calls.

## Data Use

- Data is used solely to power the new tab interface (search, display, organization).
- No data is shared with third parties.
- No profiling or advertising based on user activity.

## User Control

- Users can delete bookmarks or history at any time.
- Users can disable the extension at any time.
- Background images are stored locally; user can delete them.
